# Hasil awal kompresi image — 2 November 2026

Baseline lokal dan eksperimen prefilter sudah dapat dijalankan. Pada fixture sintetis yang diuji, **prefilter belum memberi peningkatan kualitas yang membenarkan biaya waktunya**. Karena itu feature tetap mati secara default.

## Pengaturan

- Build release, Rust 1.93.0, Linux x86_64. Ini pengukuran lokal singkat; beban mesin tidak diisolasi dan bukan pengujian performa mobile.
- Empat input PNG RGB sintetis 512×384; baseline dan tensor sama-sama menghasilkan JPEG dengan encoder `image::JpegEncoder`.
- Target bytes setiap fixture ditentukan dari JPEG baseline quality 60. Kedua metode memakai target identik, rentang quality 40–95, dan tidak memakai resize.
- Tensor: threshold 0,04, coherence boost 4, Gaussian window pada komponen tensor dan blur sigma 0,8.
- Satu warm-up per metode JPEG, lalu lima repetisi; tambahan lima operasi PNG lossless. Total 45 baris hasil.
- Seluruh hasil JPEG memenuhi target; hasil PNG mempertahankan RGBA termasuk warna tersembunyi pada alpha nol.

## PNG dan footprint

- PNG transparan menghasilkan 398 bytes dengan equality RGBA; median operasi 13,66 ms. Ini satu fixture 128×128, bukan estimasi kompresi PNG secara umum.
- Peak RSS proses benchmark: **14.236 KiB**, dibaca dari Linux `VmHWM`. Angka mencakup seluruh corpus smoke dalam satu proses, bukan peak per gambar maupun batas maksimum engine.
- Binary CLI release dengan seluruh feature saat pengukuran: **2.447.488 bytes**. Ini executable CLI, bukan ukuran library mobile atau APK; tidak mendukung klaim engine <2 MB dalam diskusi Gemini.

## Keputusan

1. Pertahankan encoder baseline dan solver sebagai jalur default.
2. Simpan prefilter sebagai eksperimen opt-in; gate keuntungan 5% belum terpenuhi pada konfigurasi/data ini, dan belum ada bukti peningkatan kualitas.
3. Tambahkan corpus foto/dokumen nyata berlisensi, metrik ROI yang lebih representatif, ablation denoise sederhana, serta sensitivitas parameter sebelum mengganti default.
4. Rate-coupled threshold, backend JPEG alternatif, dan algoritma format lain belum dievaluasi oleh hasil ini.

