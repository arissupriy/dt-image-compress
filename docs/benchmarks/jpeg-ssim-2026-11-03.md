# SSIM pada 104 keluaran JPEG native — 3 November 2026

Google jpegli tanpa prefilter mempunyai SSIM luma rata-rata tertinggi pada corpus ini dan mengungguli Turbo444 pada **11/13 sumber**. MozJPEG dan adaptive DQT memberi peringkat berbeda dari PSNR: rata-rata SSIM keduanya turun pada pasangan kontrolnya. Karena itu hasil PSNR sebelumnya tidak cukup untuk memilih satu konfigurasi terbaik bagi semua gambar.

## Data dan protokol

Pengujian memakai kembali **104 JPEG yang sudah ada**, 13 sumber × delapan metode dari [run native](jpeg-native-2026-11-03.md), tanpa encode ulang. Semua tetap memenuhi target 200.000 bytes. Hash sumber diperiksa sebelum/sesudah penilaian, ukuran keluaran dicocokkan dengan CSV, dan SHA-256 keluaran direkam. Ada 78 pasangan sumber/keluaran unik; 26 baris lainnya memakai nilai cache hanya karena kedua hash identik. Seluruh 13 pasangan T0/T1 dan 13 pasangan M0/M1 identik, termasuk SSIM.

- Decode memakai Pillow RGB dengan normalisasi EXIF. Keluaran yang di-resize dipulihkan ke ukuran asli memakai Pillow Lanczos sebelum penghitungan. Tidak ada SSIM pre-downsample; skor menilai pipeline termasuk kehilangan akibat resize.
- Luma nonlinear delapan bit: `Y=0.299R+0.587G+0.114B`. Gaussian 11×11, sigma 1,5; K1=0,01; K2=0,03; range=255; varians/covariance populasi; crop lima piksel pada batas gambar/ROI. SSIM negatif tetap diperbolehkan. Tile 256 dengan halo lima menghasilkan pusat window yang sama dengan evaluasi penuh.
- RGB PSNR dan MAE dihitung ulang dengan decoder/restorasi yang sama. **PSNR di tabel ini berbeda protokol dari PSNR Rust-image dalam laporan native**; jangan mencampur nilai absolutnya.
- Python 3.14.7, NumPy 2.4.6, SciPy 1.17.1, Pillow 12.3.0, Linux x86_64. Waktu penilaian 611,76 detik mencakup aktivitas host lain dan bukan latency engine.

Definisi Gaussian mengikuti parameter SSIM yang dijelaskan [dokumentasi scikit-image](https://scikit-image.org/docs/stable/api/skimage.metrics.html#skimage.metrics.structural_similarity); implementasi memakai SciPy dan diuji terhadap referensi weighted-window terpisah, tanpa dependency scikit-image. [Sumber penulis SSIM](https://www.cns.nyu.edu/~lcv/ssim/) juga membahas pilihan skala tampilan. Di sini skala sengaja dipertahankan pada resolusi penuh, sehingga skor tidak dianggap identik dengan protokol yang memakai prescale berdasarkan jarak pandang.

## Hasil

Rata-rata aritmetika 13 sumber, masing-masing berbobot sama; angka SSIM lebih tinggi lebih baik dalam protokol ini.

| Metode | SSIM Y rata-rata | PSNR RGB Pillow (dB) |
| --- | ---: | ---: |
| T0 Turbo444 + binary | 0,7256233 | 30,8027 |
| T1 Turbo444 + log-secant | 0,7256233 | 30,8027 |
| M0 MozJPEG + binary | 0,7197521 | 30,9239 |
| M1 MozJPEG + log-secant | 0,7197521 | 30,9239 |
| M2 MozJPEG + adaptive DQT + log-secant | 0,7188206 | 30,9350 |
| J0 jpegli/native AQ + log-secant | **0,7309251** | 30,9334 |
| M3 tensor rate-coupled + MozJPEG/DQT + log-secant | 0,7151535 | 30,9287 |
| J1 tensor rate-coupled + jpegli/native AQ + log-secant | 0,7251335 | 30,8755 |

| Pasangan | SSIM naik / sama / turun | Delta rata-rata | Rentang delta |
| --- | ---: | ---: | ---: |
| M1 vs T1: MozJPEG vs Turbo | 4 / 0 / 9 | −0,0058712 | −0,0220302…+0,0016399 |
| J0 vs T1: jpegli vs Turbo | 11 / 0 / 2 | +0,0053017 | −0,0000943…+0,0173532 |
| M2 vs M1: tambah adaptive DQT | 8 / 0 / 5 | −0,0009315 | −0,0054492…+0,0005285 |
| M3 vs M2: tambah tensor rate-coupled | 3 / 0 / 10 | −0,0036671 | −0,0318960…+0,0010487 |
| J1 vs J0: tambah tensor rate-coupled | 0 / 0 / 13 | −0,0057916 | −0,0437024…−0,0000011 |

Tie tolerance 1e−12. Dua regresi jpegli terhadap Turbo kecil dalam SSIM, tetapi tetap dicatat sebagai regresi. Kenaikan PSNR MozJPEG/DQT pada sebagian besar sumber tidak menjamin kenaikan struktur lokal menurut SSIM. Filter tetap eksperimental dan mati secara default; menumpuk algoritma belum menghasilkan keuntungan konsisten.

## Reproduksi dan artefak

```sh
python3 -m pip install -r tools/requirements-evaluation.txt
python3 -m unittest discover -s tools -p 'test_jpeg_quality.py'
python3 tools/jpeg_quality.py --samples samples \
  --run samples/results/jpeg-native-2026-11-02 \
  --output samples/results/jpeg-quality-repeat
```

Direktori output harus baru. Dibutuhkan JPEG asli dan keluaran native lokal dengan hash yang cocok; foto tidak disimpan di Git. Scorer mempunyai lima tes: identity/extremes, konstanta analitis, referensi weighted-window independen pada beberapa ukuran tile, covariance negatif, serta ROI dan validasi input.

Data versioned: [104 baris kualitas](2026-11-03-jpeg-ssim/quality.csv), [ringkasan/pasangan](2026-11-03-jpeg-ssim/summary.json), [lingkungan, definisi dan hash scorer](2026-11-03-jpeg-ssim/environment.json). Hasil lokal juga ada di `samples/results/jpeg-quality-2026-11-03/`. Pengujian ROI, waktu/RAM dan keputusan konfigurasi dilanjutkan dalam [laporan validasi produksi](jpeg-validation-2026-11-03.md).

Corpus ini berisi sepuluh foto dan tiga ilustrasi/noise, belum dipisah untuk tuning/evaluasi. Referensi adalah decode JPEG yang sudah lossy. SSIM luma tidak mengukur seluruh perubahan warna; RGB PSNR/MAE melengkapinya. Nilai ini bukan OCR, penilaian manusia, jaminan keterbacaan, atau bukti optimum global.
